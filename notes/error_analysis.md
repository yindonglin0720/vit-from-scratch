# D6 VQA 错误分析

## 一、评测方法

采用简单字符串匹配作为初版自动化评分：检查模型回答中是否包含参考答案的关键词（`reference_answer in model_answer`）。这种方法不需要额外模型，但存在明显的假错问题——模型答对了但措辞不同就会被误判为错误。

| 指标 | 数值 |
|---|---|
| 总样本数 | 31 |
| 简单匹配正确 | 22 |
| 假错（答对但文字没对上） | 7 |
| 真错（确实答错了） | 2 |
| 修正后实际正确率 | 29/31 ≈ 93.5% |

## 二、真实错误清单（2 条）

### 错误 1
- **index 25**，图片：`狗3.png`
- 问题："有几个物体"
- 参考答案：一个
- 模型回答："3 个物体"（把背景草丛里的白色小花也算进去了）

### 错误 2
- **index 26**，图片：`猫1.png`
- 问题："有几个物体"
- 参考答案：一个
- 模型回答："2 个物体"（把右上角的相机对焦图标也算进去了）

### 错误原因总结

数量判断是 4B 小模型的短板。模型对"什么是物体"的定义过于宽泛，会把背景元素（花、图标、水印）当成独立物体计入。所有 2 条真错都出现在数量类问题上，颜色、形状、物体识别、空间关系类全部答对。

## 四、成功案例（表现突出）

1. **狗品种识别**（狗1/狗2/狗3）：正确识别出"幼犬"、"比熊犬"、"哈士奇犬"，还补充了毛色、耳朵特征、项圈颜色等细节
2. **粉色识别**（0025.jpg）：回答"粉红色"，还给出了建议的 HEX 色号，超出预期
3. **空间关系**（路牌左右两个.png）：精准回答"左边是恒通路路牌，右边是恒通交通路牌"，方向标识也读对了
4. **桌子分类**（zhuozi1.png）：识别为"矮桌/茶几/榻榻米桌"，推断出日式家居风格和实木材质

## 五、下一步优化方向

1. **评分方式改人工评分**：简单字符串匹配假错率太高（7/31 = 23%），手工改成 0/1/2 分制（0=完全错误、1=部分正确、2=完全正确），能更真实反映模型能力
2. **数量类问题优化**：2 条真错都在数量类型，可在 prompt 中加约束——"只计主要物体，不计背景元素、水印或装饰"，或在微调时增加数量判断样本
