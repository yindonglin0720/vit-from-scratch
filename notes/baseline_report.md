# Zero-shot Baseline 报告

## 评估配置
- 模型：Qwen3-VL-4B-Instruct（zero-shot，无微调）
- 测试集：data/vqa_test.json，84 条
- 评分方式：exact_match（字符串匹配）+ keyword_match（关键词匹配）
- 推理参数：max_new_tokens=128, torch.float16

## 总体结果
- exact_match：52/84（61.9%）
- keyword_match：65/84（77.4%）
- 两种评分方式差 13 条（15.5%），说明关键词匹配有效减少了假错

## 按类型表现（keyword_match）
| 类型 | 得分 | 评价 |
|---|---|---|
| spatial（空间关系） | 11/12（91.7%） | 最强 |
| color_shape（颜色形状） | 16/18（88.9%） | 稳 |
| ocr（文字识别） | 11/13（84.6%） | 超预期 |
| object（物体识别） | 7/10（70.0%） | 中等 |
| count（数量判断） | 17/26（65.4%） | 最弱 |
| edge（物体边界） | 3/5（60.0%） | 最弱 |

## 主要失败原因
1. 数量判断（9条）：模型多数了项圈、领巾、背景杂物，或把"一包饼干"算成"6块"
2. 同义词（3条）："狗"vs"犬"、"桌子"vs"茶几"——关键词匹配也解决不了
3. 图片问题不匹配（3条）：问的是路牌信息但图中没有路牌

## 下一步
微调优先针对 count（数量判断）和 edge（物体边界）两类，验证 LoRA 后能否改善。
